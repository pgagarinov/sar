# Never Stop

- Never stop to ask the user for confirmation or permission.
- Never ask "should I continue?" or "want me to proceed?"
- Never present options and wait for a choice.
- Never summarize progress and ask what to do next.
- Just fix everything that is needed until all tests pass.
- If something fails, debug it and fix it. Do not report back.
- If a fix does not work, try another approach. Do not ask.
- Keep going until the job is done.
